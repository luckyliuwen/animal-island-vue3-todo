# admin-vue3

- 引入sass并配置全局sass变量
- 引入element-plus并配置全局element-plus变量,引入element-plus图标并配置全局element-plus图标
- 引入iconify图标库并配置全局iconify图标库:图标名格式为图标库:图标名
- 引入unplugin-vue-components并配置全局unplugin-vue-components:自动引入element-plus图标库
- 引入tailwindcss并配置全局tailwindcss:自动引入tailwindcss样式
- 实现layout基础布局

-## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
